## 호환성 및 설치

**Token Monitor 0.81.0 이상**이 필요합니다. Token Monitor를 설치하고 같은 컴퓨터에서 Magpie를 실행하세요. **설정 → 플러그인 → 파일에서 설치**에서 전체 폴더 또는 `.tmplugin`을 가져와 확인한 뒤 활성화합니다. Node.js를 별도로 설치할 필요는 없습니다. Notch는 지원되는 Mac에서 사용할 수 있습니다.

## 표시 위치

**메인 페이지**: 라우팅 그래프, 결정 설명, 시간 분석, 컨텍스트 및 최근 요청. 요청을 선택해 고정하고 실시간 보기로 돌아갈 수 있습니다.

**노치 패널**: 호스트 헤더에서 실시간 라우팅, 에이전트 필터, 계정 가리기 및 통계를 제공합니다. 지원되는 macOS 호스트가 필요합니다.

**가장자리 도크**: 좁은 레일에 아이콘과 요청 수를 표시하고 확장 카드에서 라우팅과 계정 목록을 보여 줍니다.

최초 설치 시 세 위치를 제안하며 확인 화면에서 변경하거나 지울 수 있습니다. 업데이트는 기존 위치를 유지하며 노치 패널, Dock 또는 백그라운드 실행을 자동으로 켜지 않습니다.

## 설정

플러그인 설정에서 포트를 선택하세요. `0`은 Magpie에 설정된 포트를 읽으며 설정이 없으면 `3425`를 사용합니다.

계정 이름은 기본적으로 가려지며 모든 보기에 동일하게 적용됩니다. 최근 요청을 선택해 고정하거나 실시간 보기로 돌아갈 수 있습니다. Magpie가 오프라인이면 마지막 데이터를 유지하고 자동으로 재연결합니다.

인터페이스는 영어, 번체 및 간체 중국어를 지원하며 그 외 앱 언어에서는 영어를 사용합니다.

## 데이터 및 실행

플러그인은 로컬 Magpie의 라우팅, 동시 실행 상태 및 컨텍스트 메타데이터를 읽습니다. 모델 요청을 보내거나 요청/응답 본문을 읽지 않으며, 계정 또는 라우팅 설정을 변경하거나 기록을 디스크에 저장하지 않습니다.

계정 가리기는 표시만 변경합니다. 메타데이터에는 도구 이름이나 파일 경로가 포함될 수 있습니다. 플러그인은 로컬 사용자 권한으로 실행됩니다.

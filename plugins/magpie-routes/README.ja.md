## 互換性とインストール

**Token Monitor 0.81.0 以降**が必要です。Token Monitor をインストールし、同じコンピュータで Magpie を起動します。**設定 → プラグイン → ファイルからインストール**で完全なフォルダまたは `.tmplugin` を読み込み、確認して有効にします。Node.js の別途インストールは不要です。ノッチパネル は対応する Mac で利用できます。

## 表示場所

**メインページ**：ルート図、判断の説明、時間分析、コンテキスト、最近のリクエスト。リクエストを選んで固定し、ライブ表示に戻せます。

**ノッチパネル**：ホストのヘッダー操作でライブのルート、エージェントフィルター、アカウント名のマスク、統計を表示します。対応する macOS ホストが必要です。

**エッジドック**：細いレールにアイコンとリクエスト数、展開カードにルートとアカウント一覧を表示します。

初回はこの3か所を提案します。インストール確認で変更・解除できます。更新は既存の配置を維持し、ノッチパネル、Dock、バックグラウンド実行を自動で有効にしません。

## 設定

プラグイン設定でポートを選択します。`0` は Magpie の設定からポートを読み、未設定なら `3425` を使います。

アカウント名は既定でマスクされ、設定は各ビューで共有します。最近のリクエストを選んで固定し、ライブ表示に戻すこともできます。Magpie がオフラインの場合は最後のデータを保持し、自動で再接続します。

UI は英語、繁体字、簡体字に対応し、それ以外のアプリ言語では英語を使います。

## データと実行

ローカル Magpie からルーティング、同時実行状態、コンテキストのメタデータを読み取ります。モデルへのリクエスト送信、リクエスト／レスポンス本文の読み取り、アカウントやルーティング設定の変更、履歴のディスク保存は行いません。

アカウント名のマスクは表示のみを変更します。メタデータにはツール名やファイルパスが含まれる場合があります。プラグインはローカルユーザー権限で動作します。

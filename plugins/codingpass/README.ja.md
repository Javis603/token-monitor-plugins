# CodingPass

Token Monitor の制限（Limits）ビューに [CodingPass](https://codingpass.ai) の 5 時間・週間・月間の利用枠の使用量とリセット時刻を表示し、プラン名、今期の終了日、利用枠リセット回数、従量課金ウォレット残高も表示します。

非公式の連携です。CodingPass には API キーで利用枠を取得するエンドポイントがないため、プラグインはブラウザのログイン Cookie を使い、`codingpass.ai/app` コンソールと同じ API を読み取ります。サイトの更新により動作しなくなる場合があります。

## 互換性とインストール

**Token Monitor 0.88.0 以降**が必要です。Windows 11 でテスト済みで、macOS と Linux は未テストです。

**設定 → プラグイン → 見つける** からインストールするか、**設定 → プラグイン → ファイルからインストール** で `.tmplugin` ファイルまたはプラグインフォルダー一式を読み込みます。内容を確認してから有効にしてください。

## 設定

1. **設定 → AIツール制限** を開き、**CodingPass** にチェックを入れて展開します。
2. ブラウザで `https://codingpass.ai/app` にログインし、F12 で開発者ツール → **Network** を開いてページを再読み込みします。
3. `usage`（または `state`）リクエストを選び、**Request Headers** の `Cookie` の値をすべてコピーします。
4. **Console Cookie header** に貼り付けて保存します。プラグインが確認し、状態が **接続済み** になれば完了です。

制限ページに 5 時間・週間・月間の枠が表示されます。上限のない枠はバーではなくメモとして表示され、5 時間枠はリクエストで開始されるまでリセット時刻を表示しません。状態が **認証情報が拒否されました** または **認証情報の有効期限切れ** になった場合は、サイトのセッションが終了しています。新しい Cookie をコピーしてください。

## データとアクセス

- ネットワーク：`https://codingpass.ai` のみ。Token Monitor の表示中の制限画面が値を要求したとき、または Cookie を確認したときだけ通信します。

  | リクエスト | 用途 |
  | --- | --- |
  | `GET /api/auth/state` | Cookie の確認（`userId` があればログイン中） |
  | `POST /api/app/usage` | 利用枠、ライブカウンター、サブスクリプション |
  | `POST /api/app/wallet` | 従量課金ウォレット残高（任意） |

- 認証情報：貼り付けた Cookie ヘッダー。Token Monitor はこのコンピューターに**暗号化せずに**保存し、プラグインは codingpass.ai にのみ送信します。ログインセッションと同等なので、共有しないでください。
- プラグインはローカルファイルを読み取らず、ほかの場所へ何も送信しません。

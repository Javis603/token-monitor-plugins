# CodingPass

Token Monitor의 한도(Limits) 보기에서 [CodingPass](https://codingpass.ai)의 5시간, 주간, 월간 한도 사용량과 초기화 시간을 보여 주고, 플랜 이름, 이번 기간 종료일, 한도 초기화 크레딧, 종량제 지갑 잔액도 표시합니다.

비공식 연동입니다. CodingPass에는 API 키로 한도를 조회하는 엔드포인트가 없으므로, 플러그인은 브라우저 로그인 Cookie로 `codingpass.ai/app` 콘솔이 사용하는 것과 같은 API를 읽습니다. 사이트가 업데이트되면 동작하지 않을 수 있습니다.

## 호환성 및 설치

**Token Monitor 0.88.0 이상**이 필요합니다. Windows 11에서 테스트했으며 macOS와 Linux는 테스트하지 않았습니다.

**설정 → 플러그인 → 탐색**에서 설치하거나, **설정 → 플러그인 → 파일에서 설치**에서 `.tmplugin` 파일 또는 전체 플러그인 폴더를 가져옵니다. 내용을 확인한 뒤 활성화하세요.

## 설정

1. **설정 → AI 도구 한도**를 열고 **CodingPass**를 선택해 펼칩니다.
2. 브라우저에서 `https://codingpass.ai/app`에 로그인하고 F12로 개발자 도구 → **Network**를 연 뒤 페이지를 새로 고칩니다.
3. `usage`(또는 `state`) 요청을 선택하고 **Request Headers**에서 `Cookie` 값을 전부 복사합니다.
4. **Console Cookie header**에 붙여 넣고 저장합니다. 플러그인이 확인하며, 상태가 **연결됨**으로 바뀌면 완료입니다.

이제 한도 페이지에 5시간, 주간, 월간 창이 표시됩니다. 상한이 없는 창은 막대 대신 메모로 표시되며, 5시간 창은 요청이 시작되기 전까지 초기화 시간을 표시하지 않습니다. 상태가 **자격 증명 거부됨** 또는 **자격 증명 만료됨**으로 바뀌면 웹사이트 세션이 끝난 것이므로 새 Cookie를 복사하세요.

## 데이터 및 접근

- 네트워크: `https://codingpass.ai`에만 접근하며, Token Monitor의 표시 중인 한도 화면이 값을 요청하거나 Cookie를 확인할 때만 요청합니다.

  | 요청 | 용도 |
  | --- | --- |
  | `GET /api/auth/state` | Cookie 확인 (`userId`가 있으면 로그인 상태) |
  | `POST /api/app/usage` | 한도 창, 실시간 카운터, 구독 정보 |
  | `POST /api/app/wallet` | 종량제 지갑 잔액 (선택) |

- 자격 증명: 붙여 넣은 Cookie 헤더입니다. Token Monitor는 이를 이 컴퓨터에 **암호화하지 않고** 저장하며, 플러그인은 codingpass.ai로만 전송합니다. 로그인 세션과 같으므로 공유하지 마세요.
- 플러그인은 로컬 파일을 읽지 않으며 다른 곳으로 아무것도 보내지 않습니다.
